# Lumina-HUB

One loader for every Lumina HUB script. It detects the game you're in and loads the right script.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/xZenbo/Lumina-HUB/main/Loader.lua"))()
```

## Supported games

| Game | Script |
| --- | --- |
| Tap Simulator REBORN | `Lumina HUB \| Tap Sim Reborn` |
| Anime Dice | `Lumina HUB \| Anime Dice` |

UI made with [Lumina](https://github.com/xZenbo/Lumina-library).
